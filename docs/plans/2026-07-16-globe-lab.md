# Globe Lab Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Build five polished, independently routed Globe Lab pages that reuse the production D3 globe and exhibition data while leaving the production experience unchanged.

**Architecture:** Add an isolated `/globe-lab` entry selected in `main.tsx`, a typed candidate registry and router, and optional visual-preset props on the existing interactive globe. Preserve production defaults and vary candidate presentation through scoped CSS variables plus a typed map-render palette.

**Tech Stack:** React 19, TypeScript, Vite, React Router 7, D3, Framer Motion, Vitest, Playwright.
