# 모바일 발열/리렌더 최적화 체크리스트 (2026-04-10)

## 목표
- 스크롤 차단 없이 모바일 사용 중 발열과 프레임 드랍을 줄인다.
- 기능 제한 없이(라이트박스, 좋아요, 댓글, 플레이리스트, 원본 링크 유지) 렌더 비용을 낮춘다.

## 이번 패치에서 적용 완료
- 프로필 썸네일 이미지 요청 해상도 축소
  - 모바일 카드 썸네일: 520px -> 260px
  - 모바일 심플 카드: 420px -> 240px
  - 모바일 플레이리스트 썸네일도 축소
- 프로필 썸네일 블러 플레이스홀더 모바일 비활성화
  - 모바일에서 GPU 비용 큰 blur 레이어 제거
- `MyPageImage` 메모이제이션 적용
  - 동일 이미지/동일 아이템의 불필요한 재렌더를 줄임
- 무한 로딩 배치 보수화
  - 초기/추가 로드 배치 축소(모바일)
  - observer rootMargin 축소로 과도한 선로딩 완화
- 라이트박스 글로벌 추천 검색량 축소
  - 모바일에서 원격 컬렉션 스캔 수 축소
  - 충분한 매칭 확보 시 조기 종료
  - 결과 상한 제한으로 상태 업데이트 폭주 방지
- 라이트박스 모바일 백드롭 blur 제거
- 라이트박스 모바일 로딩 스켈레톤 애니메이션 단순화

## 추가로 가능한 최적화 (기능 제한 없이)
- React Profiler로 실제 리렌더 병목 캡처
  - `Mypage`, 카드 그리드, 라이트박스 추천 섹션의 commit time 비교
- 카드 컴포넌트 분리 + `React.memo` 강화
  - `renderArtworkCard`/`renderSimpleCard`를 별도 컴포넌트화
  - 핸들러 `useCallback` 고정으로 prop churn 감소
- 리스트 가상화 도입 검토
  - `react-window` 또는 `@tanstack/react-virtual`로 대량 카드 렌더 상한 관리
  - 스크롤 UX 훼손 없는 범위에서 적용
- 이미지 디코딩/프리로드 정책 최적화
  - `decoding="async"`, 우선순위 조정, viewport 근접 시점 로딩
- 백그라운드 네트워크 작업 제한
  - 라이트박스 닫힘/화면 전환 시 진행 중 fetch 취소(AbortController)
- 스타일 비용 점검
  - 모바일에서 상시 `backdrop-filter` 사용 최소화
  - box-shadow/gradient 중첩 수를 화면별로 경량화
- 이벤트 핸들러 비용 점검
  - 스크롤/리사이즈 관련 핸들러에 RAF 또는 throttle 적용

## 점검 절차 (릴리즈 전)
1. 모바일 실기기에서 3분 스크롤 테스트 (프로필 500개 이상 데이터)
2. 라이트박스 연속 오픈/닫기 30회
3. 추천 작품 카드 하트/댓글/플레이리스트 액션 정상 동작 확인
4. 메모리 스냅샷 비교 (초기 진입 vs 3분 사용 후)
5. 네트워크 탭에서 불필요한 대용량 이미지 요청 여부 확인

## 성공 기준
- 동일 사용 패턴에서 기기 표면 온도 상승 체감이 이전 대비 감소
- 스크롤 중 끊김 감소(드랍 프레임 완화)
- 기존 기능 회귀 없음
