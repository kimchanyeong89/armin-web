Search

Welcome to the Manchester Art Gallery online collection search. We have adopted a new approach to searching by introducing some additional content. This blended method will allow you to use the search bar to find and view 3 types of result.

  1. Objects - objects that can be found within the collection
  2. Exhibitions - exhibitions and events where the objects were/are included
  3. Stories and themes - curated content that features objects from the collection

Use the filters on the left to customise your search, this includes the ability to select only one or more than one type of result. For example, by selecting the objects filter, you will only see object results. Enjoy!
